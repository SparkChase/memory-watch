# 内存哨兵

一个原生 macOS 菜单栏小工具。每 5 秒检查内存压力、swap 和启动盘空间，在持续异常时发出本地通知。适合不想一直盯着活动监视器、等到电脑卡顿才发现内存吃紧的人。

## 开始使用

需要 macOS 14 或更新版本，以及 Xcode Command Line Tools（可用 `xcode-select --install` 安装）。仓库提供源码，应用在本机编译。

1. 下载源码后，双击 `安装.command`，自动构建、安装到个人“应用程序”文件夹并启动；也可在终端运行 `./build.sh` 后打开生成的 `内存哨兵.app`。
2. 在 macOS 弹出的对话框中选择“允许”通知。打开工具的“设置”，点“测试通知”，确认能收到。
3. 建议勾选“登录 Mac 时启动”。需要系统批准时，会打开“登录项”设置。
4. 点击菜单栏的芯片图标查看详情。`S 4.0G` 表示 swap 使用 4.0 GiB；右键菜单可以退出。

应用不出现在 Dock 中。菜单栏拥挤或被刘海遮住时，可以按住 Command 拖动图标到容易看见的位置。重新打开应用也会显示详情面板。

通知受系统专注模式和通知设置控制。想让告警一直保留到处理，可到“系统设置 → 通知 → 内存哨兵”把样式设为“提醒”，并按需在专注模式中允许它。未允许通知时，菜单栏仍显示异常，告警仍会记录。

## 默认提醒规则

| 条件 | 持续时间 |
|---|---|
| 系统内存压力黄色 | 30 秒 |
| 系统内存压力红色 | 下一次采样立即提醒，通常在 5 秒内 |
| swap ≥ 4 GiB | 60 秒 |
| swap ≥ 8 GiB | 30 秒，可升级普通 swap 告警 |
| 磁盘可用空间 < 20 GiB | 60 秒 |
| 磁盘可用空间 < 10 GiB | 30 秒，可升级普通磁盘告警 |

同类同级告警默认间隔 15 分钟；严重告警可以提前升级，严重告警之后的普通告警也受间隔约束。提醒间隔跨应用重启保留。swap 阈值、磁盘阈值、重复间隔和声音可以在设置中调整。

调整阈值后，严重 swap 的阈值为 `max(8 GiB, 普通阈值 × 2)`，严重磁盘阈值为 `min(10 GiB, 普通阈值 ÷ 2)`。多个同轮触发的条件合并为一条通知。

睡眠时不采样，唤醒后重新计算持续时间。退出后停止监控。关闭“异常提醒”会停止通知和新增告警记录，实时读数与趋势采样继续运行。

## 自定义语音提醒（1.1.1）

内置约 8.5 秒中文语音，格式为 44.1 kHz 单声道、16 位 PCM AIFF，随应用打包。发出通知时，由应用直接播放录音，遵循同一套提醒间隔，播放中不会叠加第二段语音。可替换 `Resources/MemoryAlert.aiff` 后重新构建来更换录音。

在“设置 → 提醒声音”选择“你的录音”或“系统提示音”。“试听语音”和通知播报使用同一条应用内播放路径。“测试通知”会发送弹窗并播放录音。录音受系统音量和应用内声音开关控制，**专注模式和系统通知声音开关不会自动静音录音**。关闭“提醒时播放声音”会停止当前播报并静音后续提醒；播放中可点“停止播放”。切回“系统提示音”后遵循系统通知声音和专注模式设置。

1.1.1 修复了部分 macOS 环境中自定义通知音只有弹窗、没有录音的问题。验证命令 `./内存哨兵.app/Contents/MacOS/MemoryWatch --test-notification` 会播放一次录音，并检查播放时间推进和播放完成回调；不会仅凭弹窗送达判断语音成功。

## 怎么理解监控数据

- **内存压力**优先参考系统的正常 / 黄色 / 红色状态，不通过“空闲内存百分比”猜测压力。
- **swap 高不等于此刻一定卡顿**。已经换出的内容可能不会立刻归零；结合压力状态和当前换出速率判断。持续超出阈值仍会提醒，便于留意趋势。
- **内存已用**根据系统页统计估算，包含应用匿名内存（扣除可清除页）、内核锁定内存和压缩内存。不同采样时刻及系统统计口径可能与活动监视器略有差异。
- **进程占用**是 `ps` 的 RSS 近似值，子进程分别列出，共享页可能重复计算。它用于定位线索；要比较应用总占用，请打开“活动监视器”的“内存”页。
- **磁盘可用空间**读取用户数据所在卷的可用容量，不把“可清理空间”直接当成已释放空间。因此可能与系统“储存空间”界面有所差异。
- **单位**：1 GiB = 1024³ 字节，1 MiB = 1024² 字节。菜单栏为了简短显示 G。

## 本地记录

趋势每分钟记录一次，保留最近 24 小时；界面显示最近 1 小时的 swap 曲线与压力色点。没有历史时显示“正在积累趋势”，不会补造数据。暂停或睡眠造成的时间缺口会断开曲线。

最近 200 条告警包含当时的读数和附近时刻占用较大的 5 个进程。进程只在打开面板、手动刷新或告警时读取，避免持续运行外部命令。

文件位于 `~/Library/Application Support/MemoryWatch/`：

- `samples.jsonl`：分钟采样记录，自动压缩为有界大小。
- `incidents.json`：告警及进程快照。

可从面板右下角“更多”菜单导出 JSON。偏好设置由 macOS UserDefaults 保存。应用不上传数据，不结束进程，不清理内存或磁盘文件。

## 构建与验证

源码使用 Swift、AppKit、SwiftUI 和系统框架，无第三方依赖；按当前 Mac 的架构构建。安装 Xcode Command Line Tools 后，在项目目录执行：

```sh
./build.sh
mkdir -p .build
xcrun swiftc -swift-version 5 -O Sources/Core.swift Tests/CoreTests.swift -o .build/CoreTests
.build/CoreTests .build
./内存哨兵.app/Contents/MacOS/MemoryWatch --sample
```

`build.sh` 为当前机器架构构建并进行本机 ad-hoc 签名。这个构建没有 Apple Developer ID 公证；如果分发给其他电脑，可能被 Gatekeeper 拦截，需要另行签名和公证。

测试覆盖持续时间、冷却、升级、短暂恢复、休眠、时钟回拨、自定义阈值、未知数据、重启冷却、记录容量限制、损坏记录容错，以及本机真实采样。测试使用合成数据验证高压场景，不会故意耗尽电脑内存。

## 停用与卸载

先关闭“登录 Mac 时启动”，再退出应用。在 Finder 中手动移走 `~/Applications/内存哨兵.app` 即可。需要移除历史时，可在 Finder 中打开上述记录文件夹，逐个处理明确的记录文件。
